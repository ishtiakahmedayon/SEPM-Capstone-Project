# Ovvasjatra — Java Habit Tracker Prototype

A minimal Java Swing prototype for the academic project proposal.

## Requirements
- JDK 17 or later
- Desktop environment with Swing support

## Compile and run
Open a terminal in the `src` directory:

```bash
javac *.java
java Main
```

The app stores habits and completion records in `.ovvasjatra.dat` in the current user's home directory.

## Implemented in this prototype
- Add a daily or weekly habit
- List active habits
- Toggle today's completion
- Show today's completion count and percentage
- Local persistence

## Current limitations
This is an initial UI prototype, not the complete planned application. Editing/archiving, a date picker, and automated tests are planned for later increments.
